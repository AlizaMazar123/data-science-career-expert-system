# 🎯 Data Science Career Expert System

A simple **Python-based Expert System** that recommends a suitable career field based on a user's interests in Python, Mathematics & Statistics, Data, and Machine Learning.

This project demonstrates the use of **conditional logic and rule-based decision making** to simulate a basic expert system.

## 📌 About the Project

Choosing a career in the field of Data Science can be confusing, especially when there are multiple paths such as:

- 📊 Data Analyst
- 🤖 Machine Learning
- 🔬 Data Scientist
- 💼 Business Intelligence
- 📚 Data Science Beginner

This project asks the user a few simple questions about their interests and uses predefined rules to recommend a suitable career path.

## ⚙️ How It Works

The system asks the user four questions:

1. Do you like Python?
2. Do you like Mathematics and Statistics?
3. Do you like working with Data?
4. Are you interested in Machine Learning?

Based on the user's answers, the system applies a set of `if`, `elif`, and `else` rules to determine the recommended career field.

### Example

```text
===== Data Science Career Expert System =====

Do you like Python? (yes/no): yes
Do you like Mathematics and Statistics? (yes/no): yes
Do you like working with Data? (yes/no): yes
Are you interested in Machine Learning? (yes/no): no

--- Expert System Result ---
Recommended Field: Data Analyst

Thank you for using the Expert System!
